# Sample exported reports

These PDFs are produced by Keystone's **Download PDF** button on any generated
report (built client-side with jsPDF, so there is no print dialog). They are
included here so a reviewer can see the output quality without running the app.

- `alpha-tower-report.pdf`  — a Critical project (15% over budget, 36 days delayed)
- `beta-mall-report.pdf`    — a healthy project, on track
- `gamma-residences-report.pdf` — an At Risk project

Every dollar figure in these reports is grounded against the database by the
verifier in `evaluators/grounding.py`.
